Browser extension for rereading MS Paint Adventures in lockstep with the original updates. The link to the next page is only visible if the time you've spent reading exceeds the original time it took for the update to post.

# Installation Instructions
This plugin can be installed on Firefox and Chrome. _(It might be able to be installed on Chromium-based browsers, but I can't be bothered to check.)_
1. Click on the latest release to the right under "Releases".
2. Under "Assets", click on "Source code (zip)" to download the file.
3. Unzip (extract) the downloaded zip file.
4. Proceed to appropriate browser section.
## Firefox
5. Open Firefox and use the `MSPA-Updater.xpi` file. Firefox should prompt you to install the extension.
## Chrome
5. Go to [chrome://extensions](chrome://extensions).
6. Click the switch labeled "Developer Mode" in the upper right corner. This should reveal three buttons on the upper left side.
7. Click the button labeled "Load unpacked".
8. Navigate to the unzipped folder and open the `manifest.json` file. I think Chrome will prompt you to install the extension or something. I can't be bothered to check.
